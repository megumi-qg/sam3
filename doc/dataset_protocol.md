## Splits And Scribble Sources

| Dataset | Modality | Train | Val | Test | Scribble source |
|---|---|---:|---:|---:|---|
| ACDC | MRI | 70 cases / 1322 images | 15 cases / 314 images | 15 cases / 266 images | expert scribble |
| BTCV | CT | 20 cases / 3768 images | 4 cases / 697 images | 6 cases / 1062 images | ScribbleBench-generated train/val scribble |
| PROMISE12 | MRI | 40 cases / 1082 images | 10 cases / 295 images | 30 cases / 795 images | ScribbleBench-generated train/val scribble |

Notes:

- ACDC uses the expert scribble dataset split.
- BTCV fixes 4 cases from the original 24 training cases as validation; 6 test
  cases are kept fixed.
- PROMISE12 uses 40/10 from the train source and keeps 30 cases from the test
  source. Some train/test case names repeat, but they come from distinct local
  source subsets and are disambiguated with `train_source/` and `test_source/`
  prefixes.
- BTCV COCO JSON category names must be `bladder`, `uterus`, `rectum`, and
  `small bowel`, not `Structure_1..4`.

## Preprocessing

Main construction entry:

- `gq_scripts/preprocess/build_cmpb_clean_datasets.py`

Reused preprocessing scripts:

- `gq_scripts/preprocess/preprocess_full_annotations.py`
- `gq_scripts/preprocess/preprocess_scribble_annotations.py`

MRI uses percentile clipping. BTCV is CT and uses window level 40 / window
width 400 processing through `preprocess_full_annotations.py`.

ACDC clean data is generated by linking original images and masks and copying
JSON files with unified names. BTCV and PROMISE12 clean data are regenerated
from NIfTI sources.
