# CMPB Results Summary

Generated by:

```bash
cd /home/gaoqi/sam3
python gq_paper/cmpb/aggregate_cmpb_results.py
```

Files:

- `overall_metrics_wide.csv`: one row per model and dataset, with macro-average IoU/DSC/HD95/NSD mean and std.
- `per_structure_metrics_wide.csv`: one row per model, dataset, and anatomy.
- `metrics_long.csv`: long-format table for plotting or pivoting.
- `collected_results.json`: JSON version of the collected overall, per-structure, and long-format records.
- `source_manifest.json`: source result files and missing-file check.

Conventions:

- IoU, DSC, and NSD are stored as fractions in `[0, 1]`; multiply by 100 for paper tables if reporting percentages.
- HD95 is stored in mm.
- Paper-table precision is applied during aggregation: IoU/DSC/NSD keep 4 decimals, and HD95 keeps 2 decimals.
- `n_cases` is the number of test volumes/frames. For SAT-Pro, the original JSON reports `total_samples = cases x labels`; this summary normalizes it back to case count.
- Anatomy names are normalized across methods, for example `RV`, `right heart ventricle`, and `right ventricle` are all summarized as `right ventricle`.
