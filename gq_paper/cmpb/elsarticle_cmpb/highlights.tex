\begin{highlights}
\item SAM3 is adapted to medical segmentation using only sparse scribbles.
\item Partial mask loss ignores unlabeled pixels during mask supervision.
\item Geometric DETR losses are removed for scribble-compatible training.
\item LoRA fine-tuning reduces the number of trainable SAM3 parameters.
\item Experiments cover ACDC, BTCV\_cervix, and PROMISE12 datasets.
\end{highlights}
